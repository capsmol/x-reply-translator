X Reply Translator

Кликните в поле и нажмите новое сочетание. Нужна хотя бы одна из клавиш Ctrl, Alt (Option) или Cmd.

С ключом ответы переводит языковая модель: она видит твит, на который вы отвечаете. Без ключа — Google Translate. Подходит любой OpenAI-совместимый API. Ключ хранится только в этом браузере.

Инструкция для модели: как переводить ваш черновик. Работает только с ключом API.
